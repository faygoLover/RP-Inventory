# RP Inventory — проверка в игре (план, 20.10.2026)

Код проверен GameTest-ами (RP Inventory — 9, медицина — 40). В игре нужно посмотреть то, что видно только глазами:
экраны, HUD, закраску ячеек, Curios, ресурспаки. **Смотрит Алекс**; я готовлю инстанс и разбираю логи.

## Где
Инстанс `DEP_S5_admin` (полная сборка, одиночная игра). Я подменю jar (старые — в `minecraft/mods_backup_2026-10-20`):

| Убрать | Поставить |
|---|---|
| `InventoryFree-1.20.1-3.2.1.jar` | `rpinventory-0.1.0-1.20.1-forge.jar` |
| `rpcore-0.6.0-1.20.1-forge.jar` | `rpcore-0.7.0-1.20.1-forge.jar` |
| `rpperks-2.0.3-1.20.1-forge.jar` | `rpperks-2.1.0-1.20.1-forge.jar` |
| `rpmedicine-0.7.1-1.20.1-forge.jar` | `rpmedicine-0.8.0-1.20.1-forge.jar` |

В одиночной игре ты оператор, поэтому в мире надо выставить
`serverconfig/rpinventory-server.toml` → `exempt_gm_level = -1`, иначе ограничения на тебя не подействуют. Режим —
выживание.

## Что смотреть
1. **Инвентарь (E):** видно 9 ячеек хотбара и 9 ячеек хранилища (верхний ряд), остальные ячейки **исчезли**:
   ни рамок, ни замков, на их месте фон окна. Цвет фона совпадает с панелью (если стоит тёмный ReimaginedGUI —
   тоже тёмный).
2. **HUD-хотбар:** `/rpinv set @s hotbar 5` → внизу полоска из 5 ячеек **по центру**, вещь во второй руке — у края
   полоски. Колесо и цифры 6–9 не выбирают закрытые ячейки. `/rpinv reset @s` → снова 9.
3. **Подбор:** при заполненных открытых ячейках новые вещи не подбираются (в закрытые не попадают).
4. **Сундук:** в окне сундука твои закрытые ячейки тоже скрыты; shift-клик из сундука кладёт только в открытые.
5. **Уменьшение:** заполни хранилище, `/rpinv set @s storage 3` → лишнее переезжает в свободные открытые ячейки,
   не влезло — падает у ног, над хотбаром «Не хватило места: N предм. выпало».
6. **Броня:** надень шлем, `/rpinv set @s head 0` → ячейка шлема пропала, шлем в инвентаре; ПКМ шлемом не надевает.
7. **Вторая рука:** `/rpinv set @s offhand 0` → ячейка пропала, F не меняет руки.
8. **Curios:** `/rpinv curios` — список типов слотов и сколько их у тебя. `/rpinv set @s curios back 0` → слот
   рюкзака пропал из окна Curios, вещь из него в инвентаре. `/rpinv reset @s` → вернулся.
9. **Особенности:** возьми «Организованный» → `/rpinv show @s`: хранилище 12, в разборе `rpperks:perks storage +3`.
10. **Тело:** `/rpmedicine amputate @s left_arm` → вторая рука пропала (правша); `… right_arm` → хотбар 1 ячейка;
    `… left_leg` и `… right_leg` → пропали поножи и ботинки. Вернуть — `/rpmedicine restore @s <часть>`.
11. **Альбом Exposure:** фото кладутся в альбом (то, что ломал InventoryFree).
12. **Творческий режим** — ограничений нет; обратно в выживание — снова есть.

Обыск двумя игроками (медик видит скрытые ячейки пациента скрытыми и может взять вещь из рук в нокдауне) покрыт
GameTest-ами; вживую — при следующей совместной проверке с двумя клиентами.

Замечания — в `docs/test_findings.md` этого репозитория, исправления — после проверки.
